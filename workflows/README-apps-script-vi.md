**Apps Script Setup**

1. Mo [Google Apps Script](https://script.google.com/).
2. Tao project moi.
3. Dan noi dung tu file [google-sheet-webapp.gs](D:/Coding/Server/n8n-local-stable/workflows/google-sheet-webapp.gs).
4. Bam `Deploy` -> `New deployment`.
5. Chon `Web app`.
6. `Execute as`: `Me`.
7. `Who has access`: `Anyone`.
8. Authorize Google.
9. Copy `Web app URL`.

Gui lai `Web app URL` cho minh, minh se gan vao workflow `n8n` de tu dong ghi dong vao Sheet.
